새 폴더에 기존 RifeStandardPotPlayer.ini를 복사하면 설정과 로깅 선택을 유지합니다.
이전 폴더에서 등록 해제 후 새 폴더에서 엔진 검사와 필터 등록을 실행하세요.

Extract the entire ZIP and run RifeControl.exe. Prepare/check all engines before
registering the filter. This public package targets NVIDIA GeForce RTX 50 series.
Keep the old INI when upgrading to preserve your settings and logging choices.
v0.3.0 reduces repeated work, improves composition at 4K and above, improves
startup/seek response, and fixes affected AV1 10-bit output paths.
PotPlayer x64 and the NVIDIA driver are separate requirements.
